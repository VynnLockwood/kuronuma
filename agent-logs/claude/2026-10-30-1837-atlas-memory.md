## Decisions and assumptions
- Owner's "approve" on the plan (migration 00006, scopes `atlas:*`, native execution) was taken as all three. The two PR B loose ends and the optional duplicate guard were left at their defaults because the reply did not ask for them.
- `atlas.New(store)` takes no clock (the plan said `New(store, now)`); nothing needed one.
- **Decision for the owner: line breaks in note bodies.** Bodies go through `hermes.Untrusted` (spec and `AGENTS.md`), which collapses all whitespace, so a multi-line note is saved as one line. A newline-preserving sanitizer is a security-relevant change to make deliberately; it is best settled before anything is stored.
- **Decision for the owner: archived items.** `list_memories` without a `status` returns archived items after the open ones. The tool text now says so. Whether archived items should be hidden by default is open (the spec is silent).
